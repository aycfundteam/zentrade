# Roadmap

The project will grow around reproducibility rather than adding exchange execution.

- [ ] Add a walk-forward experiment command.
- [ ] Add public ETHUSDT and SOLUSDT datasets with pinned checksums.
- [ ] Add bootstrap confidence intervals for trade sequences.
- [ ] Add a regime-by-regime attribution report.
- [ ] Add a browser-only report viewer for generated JSON.
- [ ] Publish tagged benchmark bundles with every release.

Live exchange execution, credential custody, monitoring, and recovery remain part of the hosted zenTrade product.
